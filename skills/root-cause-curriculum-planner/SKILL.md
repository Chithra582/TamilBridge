# Root Cause Curriculum Planner Skill

## Overview
Builds targeted micro-drills that reinforce foundational concepts to eliminate multiple related surface errors simultaneously.

## Operations
1. Evaluates the learner's current dominant error fingerprint.
2. Assembles 3-5 contrastive sentence completion or transformation drills.
3. Measures error reduction after drill completion.
